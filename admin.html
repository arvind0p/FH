Access & data

Connect the dashboard to shared storage and control how data is managed.

☁

Database connection

Supabase provides shared database storage and secure administrator authentication. Credentials must be configured in admin-config.js.

Checking configuration…
  1. Create a Supabase project.
  2. Run supabase-schema.sql in SQL Editor.
  3. Add the Project URL and anon key to admin-config.js.
  4. Create an admin user in Supabase Authentication and add their user ID to admin_users.
Open Supabase ↗

Import reads the existing public pages and adds their content to empty sections in the shared database or local demo store. Review imported records before publishing.

Import / export

Import a CSV to add editable records to the connected database, or use JSON snapshots for local demo backups.

CSV imports add new records without overwriting existing records; duplicates are skipped. Imported records default to draft unless a status is supplied. JSON import is for local demo mode only.

Before publishing

  • Confirm the correct Supabase project URL and anon key.
  • Enable Row Level Security (RLS) using the supplied schema.
  • Only grant dashboard access to authorized admin accounts.
  • Never put a service-role key in browser code.
  • Connect public pages to the same content tables before expecting edits to appear on the live website.
